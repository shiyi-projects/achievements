# Achievements — UI 设计规范

> 基于 PRD 功能列表，采用 Material Design 3 + Flutter 实现的高品质 Todo 应用。

---

## 1. 设计理念

| 维度 | 描述 |
|------|------|
| **风格** | 现代极简 + 轻拟物，M3 Tonal Elevation 取代传统阴影 |
| **情感** | 温暖、有成就感、游戏化激励 |
| **核心原则** | 清晰层级 · 流畅动效 · 一致性 · 无障碍 |

## 2. 色彩系统

采用 `ColorScheme.fromSeed()` 生成，支持 Light / Dark / Dynamic Color。

### 2.1 种子色与主色调

```
Seed Color: #6750A4 (Deep Purple)
```

### 2.2 语义色彩角色（Light Mode）

| 角色 | 色值 | 用途 |
|------|------|------|
| `primary` | #6750A4 | 主按钮、FAB、关键操作 |
| `onPrimary` | #FFFFFF | primary 上的文字/图标 |
| `primaryContainer` | #EADDFF | 选中状态卡片、标签背景 |
| `secondary` | #625B71 | 次要操作、辅助图标 |
| `secondaryContainer` | #E8DEF8 | 侧边栏选中项背景 |
| `tertiary` | #7D5260 | 强调色、成就系统、专注模式 |
| `tertiaryContainer` | #FFD8E4 | 成就卡片、专注统计背景 |
| `surface` | #FFFBFE | 页面背景 |
| `surfaceContainer` | #F3EDF7 | 卡片、列表项背景 |
| `surfaceContainerHigh` | #ECE6F0 | 抬升卡片、对话框 |
| `error` | #B3261E | 删除、过期提醒 |
| `outline` | #79747E | 边框、分割线 |
| `outlineVariant` | #CAC4D0 | 次级分割线 |

### 2.3 Dark Mode

通过 `ColorScheme.fromSeed(brightness: Brightness.dark)` 自动生成互补暗色方案。

### 2.4 任务优先级色彩

| 优先级 | 色值 | 标识 |
|--------|------|------|
| 🔴 紧急 | #DC362E | 实心圆点 + 左侧色条 |
| 🟠 高 | #E8710A | 实心圆点 + 左侧色条 |

## 7. 组件规范

### 7.1 任务输入框

```dart
// 快速添加任务输入框
Container(
  decoration: BoxDecoration(
    color: colorScheme.surfaceContainerHigh,
    borderRadius: BorderRadius.circular(16),
  ),
  child: TextField(
    decoration: InputDecoration(
      prefixIcon: Icon(Icons.add_circle_outline),
      hintText: '添加任务...',
      border: InputBorder.none,
    ),
  ),
)
```

### 7.2 Checkbox

- 形状：圆形（`CircleBorder`）
- 未选中：`outline` 色 2dp 边框
- 选中：`primary` 填充 + 白色 ✓
- 动画：缩放弹性 + 打勾绘制（200ms，`Curves.easeOutBack`）

### 7.3 任务 Chip / 标签

- 圆角 8px
- 背景：对应颜色的 Container 变体（透明度 12%）
- 文字：`labelMedium`，对应颜色 `onContainer`

### 7.4 FAB（移动端）

- 位置：右下角
- 样式：M3 `FloatingActionButton.large`
- 图标：`Icons.add`
- 颜色：`primaryContainer` / `onPrimaryContainer`

### 7.5 底部导航栏（移动端）

```
┌────────┬────────┬────────┬────────┐
│  Today │  日历  │  专注  │  统计  │
│   ☀    │  📅   │   🧘   │  📊   │
└────────┴────────┴────────┴────────┘
```

- 使用 M3 `NavigationBar`
- 选中项带 `secondaryContainer` 指示器
- 动画：图标放大 + 指示器滑入

### 7.6 空状态

- 居中布局
- 顶部：64dp 淡色插画图标
- 中间：`titleMedium` 主文案（如"还没有任务"）
- 底部：`bodySmall` 鼓励语 + 操作按钮
- 插画风格：线性 + 柔和渐变

## 8. 动效规范

### 8.1 通用参数

| 动效类型 | 时长 | 曲线 |
|----------|------|------|
| 微交互（Checkbox、按钮） | 150-200ms | `easeOutBack` |
| 列表项增删 | 300ms | `easeInOut` |
| 页面切换 | 350ms | `easeInOutCubicEmphasized` |
| 底部弹窗 | 300ms | `easeOutCubic` |
| 展开/折叠 | 250ms | `easeInOut` |
| 拖拽回弹 | 200ms | `easeOut` |

### 8.2 关键动效

| 场景 | 动效描述 |
|------|----------|
| **任务完成** | Checkbox 弹性缩放 → 打勾绘制 → 标题删除线滑入 → 卡片淡出下移 |
| **任务创建** | 输入框展开 → 新卡片从上方滑入 + 淡入 |
| **拖拽排序** | 长按抬升（elevation + scale 1.03） → 其他卡片让位动画 |
| **页面切换** | M3 共享轴动画（SharedAxisTransition） |
| **成就解锁** | 金光粒子爆发 → 图标旋转放大 → Badge 弹入 |
| **番茄钟结束** | 圆环填满 → 脉冲闪烁 → 庆祝粒子 |
| **下拉刷新** | M3 拉伸指示器（`RefreshIndicator`） |
| **数字滚动** | 统计数字按位翻转动画（`AnimatedSwitcher`） |
| **侧边栏** | 滑入 + 背景遮罩淡入 |

### 8.3 手势交互（移动端）

| 手势 | 操作 |
|------|------|
| 左滑任务卡片 | 显示删除操作（红色背景 + 🗑） |
| 右滑任务卡片 | 快速完成（绿色背景 + ✓） |
| 长按任务卡片 | 进入多选模式 / 拖拽排序 |
| 下拉 | 刷新 |

## 12. 无障碍规范

| 规则 | 要求 |
|------|------|
| 对比度 | 文字与背景对比度 ≥ 4.5:1（AA 级） |
| 触摸目标 | 最小 48×48 dp |
| Semantics | 所有交互元素添加 `Semantics` 标签 |
| 字体缩放 | 支持系统字体缩放至 200% |
| 屏幕阅读器 | 自定义组件提供 `label`、`hint`、`value` |
